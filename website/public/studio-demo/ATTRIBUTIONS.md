# A small act of care

Original code: **Stitchable.ai and EditableFrames contributors**, MIT.
Ported from [EditableFrames](https://github.com/Stitchable-ai/editable-frames), revision `d33b612fee3e4e9ca88ba28f3b9c7ee34c001df3`. The MIT license is included in this package. This is a port of the actual original procedural study, not third-party video or model assets.

The study catalog credits **@devteamdrew** as a creative reference (reference study 3). That is an inspiration credit, not the author or license of this code. An original paper robot discovers a seed, waters it and shelters its first leaf. Pose holds, paper shadows and a page turn.

Package changes: a portable explicit-frame renderer, editable original art direction and narrative text, deferred browser allocation, closed local source dependencies. Default values retain the original composition. No network resources or model assets are fetched.

Website adaptation: a second paper robot, independently colored and animated, is
added for the Stitchable Studio guided annotation preview. The surrounding app
illustration is authored for this website; it does not embed the desktop app.

The website's second scene adds matched-size gardeners holding hands, an authored
watering can, source-time water sprinkles, hearts and a smiling sunflower. It
extends the guided example to a 24-second, two-scene video with real restart
playback. All added artwork is code-drawn; no additional media assets are used.
