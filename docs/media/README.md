# README demonstration media

`edit-in-motion.gif` captures the real film-study editor and its procedural castle. It contains 96 frames at 8 fps (12 seconds), with the controls beside the rendered scene. The source clock advances explicitly between screenshots to make the capture repeatable.

Actions are actual UI interactions: raise Tower height from 1 to 1.4, set Trees from 36 to 0, undo twice, and redo once. `capture-receipt.json` records the resulting property states and browser errors (none). The scene continues to advance through its camera animation between actions. The still image provides a non-animated alternative.

The recording uses the standalone film study, whose edits can be saved by downloading a project snapshot. Disk-backed project previews additionally persist edits immediately. This GIF does not demonstrate a hosted account, a remote agent session or an export.

Gallery thumbnails elsewhere in the README are existing renders from `apps/films/previews`, `apps/effects/previews` and `assets/devices/previews`. No private posts or third-party screenshots are included. Device credits are in `assets/devices/ATTRIBUTIONS.txt`.
