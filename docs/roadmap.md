# After beta 1

The implemented beta contract and verification commands are in [beta.md](beta.md).

1. Isolated compiler/renderer and capability-scoped asset services for untrusted host integrations, including Stitchable.
2. Streaming demux/decode with bounded on-disk caches, hardware backends, performance benchmarks and native webview parity.
3. Audio automation, exact browser audio scheduling, mastering/loudness and additional export containers/deliverables.
4. Explicit source/schema migration maps, restoring historic dependency graphs, incremental timeline state and large-project benchmarks.
5. DOM capture and additional output adapters, depth ordering between clips and general layer/simulation services, measured EffectCraft/WASM bridges. For [hybrid scenes](hybrid-scenes.md): depth of field and lens matching, light wrap, linear-light compositing, shadows and reflections cast onto footage, and a real-footage acceptance set.
6. Unify device looks and more film/effect studies as generic project adapters; finish per-model screen calibration.
7. Promote research labs for maps, fashion, avatars and other genres using the same media/adapter/credit contracts.
8. Validate live agent-host installation and evaluate MCP packaging; publish an actual repository/release and asset-pack URLs when requested.

New libraries remain possible. These are missing host services and production guarantees, not a closed list of permitted scene types.
