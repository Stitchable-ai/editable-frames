## Generation workflow: tested contract before host integration

The local prototype freezes scene revision, action, provider/model and ordered reference hashes. It persists an attempt marker before any external transport would begin. A forced process exit at that point reopens as ambiguous; automatic retry is refused. Explicit provider-ID reconciliation can resume the record. Two concurrent owners cannot both start the same row.

Changed reference order/bytes, changed endpoint/action and stale revisions are rejected. Decoding is separate from visual acceptance. Corrupt or failed replacements preserve the last accepted take across restart; a modified output cannot be accepted. Variable-rate media requires an explicit conform step.
